# 自定义音频播放设计

## 目标

在现有内置声音播放器基础上，增加第一版自定义音频能力。用户可以从本地选择音频文件，把它添加到声音库中，并像内置声音一样播放、暂停、调音量和停止全部声音。

## 第一版范围

第一版包含：

- 从本地选择一个或多个音频文件。
- 支持常见浏览器可播放音频格式，例如 `mp3`、`ogg`、`wav`、`m4a`、`aac`、`flac`、`webm`。
- 把音频文件 Blob 存入浏览器或 WebView 的 IndexedDB。
- 应用启动时恢复已添加的自定义音频。
- 自定义音频显示在声音库中。
- 自定义音频可以播放、暂停、调音量。
- 统一播放/停止按钮需要继续能停止自定义音频。
- 用户可以删除自定义音频。
- 删除正在播放的自定义音频前，先停止该音频。

第一版不包含：

- 自定义音频加入内置预设。
- 自定义预设。
- 云端同步。
- 音频转码。
- 音频裁剪。
- 编辑自定义音频名称。
- 导入目录。
- DRM 或受保护媒体处理。
- Android 原生文件路径播放器。

## 平台策略

Web、Linux、Windows 和 Android 都使用同一套 React UI。

自定义音频第一版采用 IndexedDB 保存 Blob，播放时创建 `blob:` URL 并交给 HTMLAudio 播放。这样不需要额外文件系统插件，也能在 Web 和 Tauri WebView 中保持较一致的行为。

Android 内置音频仍使用 Kotlin `MediaPlayer` 播放 Android raw 资源。自定义音频不进入 Android raw 资源，也不使用原生文件路径，第一版在 Android 上由 WebView 音频能力播放。

因此 Android 播放适配器需要变为组合适配器：

```text
AndroidHybridPlayer
  -> 内置声音：AndroidNativePlayer
  -> 自定义声音：WebAudioPlayer
```

这不会改变 UI 对 `PlayerPort` 的依赖。

## 数据模型

声音 ID 分为两类：

```ts
type BuiltInSoundId = "heavy_rain" | "...";
type CustomSoundId = `custom:${string}`;
type SoundId = BuiltInSoundId | CustomSoundId;
```

声音定义增加来源类型：

```ts
interface SoundDefinition {
  id: SoundId;
  name: string;
  sourceKind: "built-in" | "custom";
  androidResourceName?: string;
  imageSrc: string;
  sources: AudioSourceDefinition[];
}
```

自定义音频存储记录：

```ts
interface StoredCustomSound {
  id: CustomSoundId;
  name: string;
  type: string;
  blob: Blob;
  createdAt: number;
}
```

自定义音频恢复时，把 Blob 转成对象 URL：

```text
StoredCustomSound.blob -> URL.createObjectURL(blob) -> SoundDefinition.sources[0].src
```

组件卸载或删除音频时必须释放对象 URL，避免长期占用内存。

## UI 设计

声音库顶部增加“添加自定义音频”区域：

- 显示简短说明。
- 提供本地文件选择按钮。
- 显示导入中、导入成功或导入失败状态。

声音网格继续显示内置声音和自定义声音。自定义声音卡片带“移除”操作。移除按钮只出现在自定义音频卡片上，内置声音不能删除。

## 状态规则

- 自定义音频导入后默认音量为 `0.5`。
- 点击自定义音频卡片调用 `PlayerPort.play(sound, volume)`。
- 自定义音频暂停调用 `PlayerPort.pause(soundId)`。
- 自定义音频调音量调用 `PlayerPort.setVolume(soundId, volume)`。
- 删除自定义音频时，如果该音频正在播放，先调用暂停流程，再删除 IndexedDB 记录和 UI 状态。
- 停止全部声音时，组合播放器需要同时停止原生播放器和 Web 音频播放器。

## 错误处理

- 当前环境不支持本地持久化时，仍允许应用加载，但导入自定义音频会给出明确错误。
- 非音频文件或不支持的扩展名不允许导入。
- IndexedDB 写入失败时显示导入失败提示，不把不完整记录加入 UI。
- 播放失败沿用现有播放器错误提示。

## 验收标准

- 自定义音频存储工具能识别支持和不支持的文件。
- 自定义音频能转换成 `SoundDefinition`。
- Web 播放器可以播放 `blob:` URL。
- Android 组合播放器把内置声音路由到原生播放器，把自定义音频路由到 Web 播放器。
- UI 显示“添加音频”入口和自定义音频说明。
- UI 删除自定义音频时不会影响内置声音。
- 必须通过：

```bash
pnpm run check
```

Android 自定义音频真机播放需要用户手动验证。agent 除非实际运行过真机导入和播放，不得声称真机验证通过。
