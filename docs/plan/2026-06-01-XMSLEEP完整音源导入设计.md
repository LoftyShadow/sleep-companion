# XMSLEEP 完整音源导入设计

## 目标

把参考项目 `/home/niemingzhi/IdeaProjects/XMSLEEP` 中尚未接入的声音导入梦伴，让用户可以在新增的“其他声音”调音台页签里浏览和播放 XMSLEEP 补充音源。用户指定的“咖啡厅”归入“白噪音”；“其他声音”只展示现有“白噪音”和“ASMR”以及指定归入白噪音的声音之外的补充声音。

## 范围

本次包含：

- 以 XMSLEEP 根目录的 `sounds_remote.json` 作为完整音源清单来源。
- 复制清单中每个声音对应的本地 `audio/**/*.ogg` 文件到本项目。
- Web、Linux、Windows 使用 `public/audio/xmsleep/` 下的文件播放。
- Android 使用 `src-tauri/gen/android/app/src/main/res/raw/` 下的合法 raw 资源播放。
- 顶层声音模式新增“其他声音”页签。
- “白噪音”继续显示原有内容和预设，并额外显示 XMSLEEP 的“咖啡厅”。
- “ASMR”继续只显示原有内容和预设。
- “其他声音”只展示 XMSLEEP 中没有被现有白噪音、ASMR 或指定白噪音补充项覆盖的补充音源。
- “其他声音”按 XMSLEEP 原始分类筛选：自然、雨声、城市、场所、交通、物品、噪音、动物。
- 如果 XMSLEEP 项目里存在可直接复用的同名声音图片，优先使用 XMSLEEP 的图片。
- 如果 XMSLEEP 没有对应图片，为该声音基于 XMSLEEP 音频生成本项目内的波形图。
- 保留现有自定义音频能力，并调整上传区布局：按钮在最右侧，“选文件即上传”的提示在按钮左侧。

本次不包含：

- 接入 XMSLEEP 的远程下载缓存架构。
- 复制 XMSLEEP 的大型 Android 播放服务、通知、后台播放或远程音频管理架构。
- 为完整音源新增收藏、搜索、下载进度或用户自定义分类。
- 删除或替换已有 17 个白噪音和 10 个 ASMR 条目。

## 资源策略

XMSLEEP 完整音源使用独立 ID 前缀：

```text
xmsleep_<原始 id 合法化后名称>
```

例如：

```text
rain-on-car-roof -> xmsleep_rain_on_car_roof
ear-cleaning-1 -> xmsleep_ear_cleaning_1
```

这样可以同时保留现有的 `campfire`、`keyboard`、`asmr_keyboard_taps` 等既有条目，又能完整导入 XMSLEEP 清单里的同名或同素材声音。

Web 音频路径：

```text
public/audio/xmsleep/<category>/<legal-name>.ogg
```

Android raw 路径：

```text
src-tauri/gen/android/app/src/main/res/raw/xmsleep_<legal-name>.ogg
```

图片路径：

```text
public/images/sounds/xmsleep/<legal-name>.webp
```

## 去重策略

本项目保留完整 XMSLEEP 导入清单，用于资源校验和未来扩展；UI 的“其他声音”只使用去重后的补充集合。

去重依据优先级：

1. 已有 ASMR 素材清单中的 XMSLEEP 来源文件。
2. 现有 17 个白噪音的 XMSLEEP raw 来源或明显同源声音。
3. 名称和用途明确重复的声音，例如 `keyboard`、`typewriter`、`clock`、`heavy-rain`。

另外，`cafe` 按用户要求归入“白噪音”，也不出现在“其他声音”中。

完整 XMSLEEP 清单仍为 113 个声音；“白噪音”标签额外展示 1 个 XMSLEEP 补充声音，XMSLEEP 分类标签共覆盖 91 个去重后的补充声音。

## UI 设计

声音库使用统一声音标签筛选，包含全部、白噪音、ASMR、XMSLEEP 原始分类和自定义音频：

- 白噪音：显示现有 17 个白噪音和 XMSLEEP 咖啡厅。
- ASMR：显示现有 10 个 ASMR 声音；ASMR 推荐混音统一展示在“推荐与我的混音”区域。
- XMSLEEP 分类：自然、雨声、城市、场所、交通、物品、噪音、动物直接作为声音标签，显示去重后的补充音源。
- 自定义音频：只显示用户导入的本地音频。

声音库继续复用 `SoundGrid`，因此播放、暂停和单独音量控制逻辑仍通过 `PlayerPort` 统一执行。当前混音集中显示在全局混音工作台中，不随标签筛选切换。

统一播放按钮现在作为全局混音控制使用，不再随白噪音、ASMR 或 XMSLEEP 分类标签切换播放目标；声音标签只影响声音库筛选。

## 验收标准

- `sounds_remote.json` 中的所有声音都有对应 `SoundDefinition`。
- 每个 XMSLEEP 声音都有 Web 音频文件、Android raw 音频文件和图片文件。
- Android raw 资源名只包含小写字母、数字和下划线，且以字母开头。
- 现有白噪音和 ASMR 清单保持可用。
- UI 声音库显示“全部”、“白噪音”、“ASMR”、XMSLEEP 原始分类和“自定义音频”声音标签。
- “白噪音”能看到 XMSLEEP 咖啡厅。
- XMSLEEP 分类标签只展示去掉已有白噪音、ASMR 和 XMSLEEP 咖啡厅后的补充声音。
- XMSLEEP 原始分类不再挂在“其他声音”中间入口下。
- 自定义音频上传区按钮位于最右侧，提示位于按钮左侧。
- 必须通过：

```bash
pnpm run check
```

如果 Android 真机环境未运行，不声明真机播放已验证。
