# B 站视频收藏设计

## 背景

“听视频”已经改为直连模式，用户可以通过输入 `BV` 或 `av` 载入视频，也可以从已保存 UP 主的公开视频列表中选择视频。当前问题是常听的视频每次都要重新输入或重新刷新 UP 主列表，流程偏长。

本轮新增本地视频收藏，用于保存常听视频的展示信息和播放入口。收藏只保存视频标识和元信息，不保存 B 站登录凭证、Cookie、直连音频 URL 或直连视频 URL。

## 目标

- 用户可把当前已载入的视频加入收藏。
- 收藏列表持久化到本地 `FileSystemPort`，在 Web 环境落到 IndexedDB。
- 用户可从收藏列表直接选择视频并重新载入直连媒体播放。
- 收藏项显示标题、封面、BV/av、时长、发布时间、播放量和收藏时间中可用的信息。
- 用户可删除已收藏视频。
- 收藏重复视频时更新元信息，不产生重复项。

## 非目标

- 不同步到云端或 B 站官方收藏夹。
- 不保存播放进度。
- 不保存直连 `audioUrl`、`videoUrl`、备用流地址或任何带签名的媒体地址。
- 不实现收藏分组、搜索、排序切换或批量管理。

## 数据模型

收藏项使用 `BilibiliFavoriteVideo`：

- `bvid`：必填，主键。
- `aid`：可选，用于展示 `av`。
- `title`：必填。
- `coverUrl`：可选封面。
- `durationSeconds`：可选时长。
- `publishedAt`：可选发布时间，单位秒。
- `playCount`：可选播放量。
- `addedAt`：首次收藏时间。
- `updatedAt`：最近更新收藏元信息时间。
- `source`：可选，标记来源为手动输入、UP 主列表或直连载入。

本地存储路径：

```text
video-listening/bilibili-favorite-videos.json
```

## 架构

### 存储层

- 新增 `bilibiliFavoriteVideoStore.ts`。
- 复用 `FileSystemPort` 和 `indexedDbFileSystem`。
- `listBilibiliFavoriteVideos` 读取并过滤非法数据。
- `upsertBilibiliFavoriteVideo` 新增或更新单条收藏。
- `deleteBilibiliFavoriteVideo` 删除指定 `bvid`。
- 列表按 `updatedAt` 倒序展示。

### 状态层

- 新增 `useBilibiliFavoriteVideos.ts`。
- 组件挂载时读取本地收藏。
- 提供 `saveFavorite`、`deleteFavorite` 和 `isFavorite`。
- 存储失败时在收藏面板内显示错误，不影响播放器。

### UI 层

- 新增 `BilibiliFavoriteVideoPanel.tsx`。
- 面板展示收藏数量、当前视频收藏按钮、收藏列表和删除按钮。
- 点击收藏项时调用现有直连加载流程。
- 收藏当前视频时从已载入的直连响应和元信息组装收藏元数据。

### 播放数据流

1. 用户输入或从 UP 主列表选择视频。
2. 前端调用现有直连 loader。
3. loader 返回标题、封面、`bvid`、`aid` 和媒体地址。
4. 页面只把标题、封面、`bvid`、`aid` 等元信息交给收藏模块。
5. 用户点击收藏，收藏模块写入本地 JSON。
6. 用户以后点击收藏项，页面使用 `bvid` 重新调用直连 loader。

## 失败路径

- 本地收藏文件不存在：展示空列表。
- 本地收藏文件格式损坏：忽略损坏内容并展示空列表。
- 收藏写入失败：保留播放器状态，显示收藏错误。
- 点击收藏项后 B 站直连解析失败：沿用现有直连错误提示。
- 收藏项缺少可选字段：只展示可用信息。

## 验收标准

- 已载入 `BV/av` 视频后可以点击“收藏视频”。
- 收藏成功后列表出现该视频，再次点击同一视频不新增重复项。
- 点击收藏项会重新调用直连 loader 并播放对应 `bvid`。
- 可以删除收藏项，删除后列表更新。
- 本地存储中不包含 `audioUrl`、`videoUrl`、`backupUrls`、Cookie 或登录凭证。
- 必须通过 `pnpm run check`。

## 风险

- B 站视频可能下架或权限变化，收藏项仍存在但后续播放会失败。
- 封面 URL 可能失效，失效时只影响展示。
- 收藏只保存在当前浏览器或当前应用本地环境，不跨设备同步。
