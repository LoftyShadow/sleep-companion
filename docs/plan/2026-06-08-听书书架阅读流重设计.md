# 听书书架阅读流重设计

## 背景

当前听书页面已经具备本地书架、导入、删除、继续播放、章节导航和片段朗读能力，但界面把书架、朗读状态、导入设置和正文片段全部放在同一屏。用户在听书入口中首先看到的是控制台式布局，书架只占左侧窄栏，缺少“先选书，再进入朗读内容”的清晰路径。

本次改造只调整前端信息架构、视觉层级和页面状态，不修改 TTS 引擎、书籍导入、IndexedDB 存储、EPUB 解析和播放进度保存逻辑。

## 目标

- 听书入口默认呈现宽幅书架效果。
- 只要存在最近打开的书，书架页顶部也显示当前书播放控制条，方便直接继续播放上次记录。
- 书籍以更像书架陈列的卡片方式展示封面、标题、作者、格式、章节数、片段数和进度。
- 点击书籍后进入具体朗读内容页。
- 朗读内容页保留播放控制、状态、章节导航、片段列表、书名编辑、音色和语速设置。
- 朗读内容页提供明确的“返回书架”入口。
- 导入新书仍可在书架页完成；空书架时提供清晰的导入入口。

## 非目标

- 不新增搜索、排序、分组、批量管理或收藏能力。
- 不新增真实图书阅读器、划线、笔记或 EPUB CFI 定位。
- 不改动存储结构和已有书库数据模型。
- 不改变浮动播放控制、全局停止和睡眠模块对听书的调用方式。

## 交互设计

### 书架态

- 页面主体为 `AudiobookLibraryPanel`。
- 如果已有最近打开的书，书架上方展示当前书播放控制条，可直接播放、暂停、上一段、下一段和停止。
- 顶部展示“听书书架”、书籍数量和导入入口。
- 书籍列表使用响应式网格陈列，卡片内封面占主要视觉位置。
- 点击卡片主体打开书籍并进入阅读态。
- 删除按钮保留在卡片内，但与打开操作保持明确分离。

### 阅读态

- 顶部复用当前书朗读控制条，包含返回书架、标题、章节/片段/进度指标、状态和播放按钮。
- 下方为左右工作区：左侧是朗读准备和设置，右侧是朗读内容。
- 小屏幕下改为单列堆叠，避免横向滚动。

## 组件边界

- `AudiobookView`：维护书架态和阅读态，编排书架、控制条、设置区和正文区。
- `AudiobookLibraryPanel`：只负责书架展示、导入、打开和删除。
- `AudiobookReader`：继续负责正文编辑、章节导航和片段定位。
- `AudiobookImportPanel`：继续负责当前书名编辑和文件拖拽导入。
- `AudiobookSettingsPanel`：继续负责音色与语速。
- `AudiobookTransport` 和 `AudiobookStatusPanel`：继续负责播放控制与状态显示。

## 视觉原则

- 沿用当前梦伴的雾面玻璃、青绿色主色和 8px 圆角体系。
- 书架卡片增加书脊、层板和封面厚度感，但仍用 CSS 原生实现，不引入位图装饰。
- 所有可点击区域保持不小于 44px 的触控目标。
- 保留可见焦点态，动画控制在 150-300ms，并支持 `prefers-reduced-motion`。
- 页面状态使用语义元素和清晰标题层级，避免把主要交互做成不可访问的装饰层。

## 验收标准

- 默认进入听书入口时显示书架工作台。
- 存在最近打开书籍时，书架工作台顶部显示可直接操作的继续播放控制条。
- 书架中点击某本书后进入该书的朗读内容页。
- 书架页点击“进入内容”后进入当前书的朗读内容页。
- 阅读页点击“返回书架”后回到书架工作台，当前播放状态不被该操作强制停止。
- 新导入书籍后进入朗读内容页，保持现有导入后自动打开行为。
- 删除当前打开书籍时停止朗读，并回到书架态或打开下一本书。
- 现有导入、重命名、音色、语速、章节切换、片段播放和浮动播放控制能力不回退。
- 完成后运行 `pnpm run check`。
