# 听视频控制台视觉重设计

## 背景

当前听视频页已经拆分为链接输入、收听面板、视频画面、视频收藏和 UP 主列表。页面功能完整，但视觉上存在几个问题：

- 输入区、收听面板和视频画面主次层级不够清晰，上一版强化后又出现深色舞台、网格和圆盘装饰过重的问题。
- 视频画面未载入时看起来像大面积空白占位，或在装饰过强时显得过于抽象。
- 收藏和 UP 主区域与顶部播放区视觉权重接近，用户第一次进入时不容易判断核心操作顺序。
- 页面整体偏单一绿色玻璃风格，和“夜间收听视频”的使用场景不够贴合。

## 目标

- 保留现有信息架构和所有播放、收藏、UP 主列表行为。
- 将顶部核心区改成更直接的听视频工具面板：链接载入、当前收听和视频画面都保持清楚的操作边界。
- 视频画面空状态要像可展开的媒体预览区，而不是空白表单，也不要依赖抽象 CSS 图形。
- 收藏和 UP 主区域保持可扫读，但视觉权重低于核心播放链路。
- 所有改动限制在听视频 feature 的组件和 scoped CSS 内，不改全局设计系统。

## 非目标

- 不改变 B 站链接解析、直连音频获取、收藏存储、UP 主刷新或登录逻辑。
- 不引入新的第三方 UI 库或图标库。
- 不新增视频播放能力，例如倍速、弹幕、播放列表或进度持久化。
- 不改动其它模式页面的设计语言。

## 组件边界

- `VideoListeningView`：继续负责页面编排和 controller 接线。
- `VideoLinkPanel`：继续负责视频链接输入、粘贴和载入。
- `VideoNowPanel`：继续负责当前收听卡片、播放按钮、音量和状态。
- `BilibiliVideoPlaybackPanel`：继续负责进度条、视频画面、画质选择和媒体源详情。
- `BilibiliFavoriteVideoPanel`：继续负责当前视频收藏和收藏列表。
- `BilibiliCreatorPanel`：继续负责登录入口、UP 主保存、刷新和公开视频列表。
- `VideoListeningView.css`：承担本轮视觉重设计的样式作用域。

## 设计方案

采用“简化媒体工具面板”方向：

- 链接输入区回到浅色工具卡片，只保留标题、输入框、按钮和状态文案，不再放置抽象插图。
- 当前收听面板保留浅色高可读卡片，封面空状态保持简单标识，不新增装饰图形。
- 播放控制区使用浅色控制条，播放按钮保持明确主操作，音量滑块和提示文案不抢视觉权重。
- 视频画面折叠状态使用浅色状态框和直接文案，不再使用播放插图、网格或圆盘等抽象装饰。
- 收藏、UP 主和公开视频列表继续使用浅色面板，但减少强玻璃反光，强化列表和选中态。
- B 站登录不再作为来源 tab 占用输入区空间，改成来源行右侧的头像入口；未登录时点击头像展开完整登录弹层，二维码和 Cookie 导入必须在弹层内完整可见，已登录时头像代表当前账号。
- 普通 Web 端不能跨域读取外部 `bilibili.com` 登录 Cookie，因此不展示“网页登录 / 同步登录”；Web 端只展示扫码登录和 Cookie 导入。Tauri 桌面端可以通过独立 Webview Cookie API 同步，才保留网页登录和同步登录。
- 已登录时点击头像或账号按钮只展开账号操作区，不直接退出；退出登录放在展开区内的红色按钮中，避免误触。
- UP 主区域参考 B 站动态页的信息组织方式：保存的 UP 主使用横向头像选择 rail，进入或切换 UP 主时默认刷新公开视频，删除入口放在头像项右上角，最新公开视频紧接 rail 展示，避免额外操作条挤占最近视频的可视空间。
- UP 主公开视频改为按 B 站投稿页分页获取，每页展示 5 条；分页操作放在 UP 主头像选择区和视频列表之间，并在接口返回总数时展示总页数，列表区域允许滚轮浏览，避免左侧面板被视频数量撑高。
- UP 主头像 rail 和登录摘要只展示用户能识别的名称或头像，不展示 `mid` 这类内部编号。
- 所有圆角维持 8px，符合仓库现有控制台风格。
- 动效只用于 hover 和状态反馈，并通过 `prefers-reduced-motion` 降级。

## 验收标准

- 听视频页的链接输入、载入、播放、音量、画面展开、收藏和 UP 主列表入口仍可见且布局稳定。
- 桌面宽度下顶部核心区左右并排；中窄屏下自然堆叠，无横向滚动。
- 小屏下输入按钮、收藏操作和 UP 主操作不溢出容器。
- 登录入口保持头像大小，不挤占来源按钮和最近视频展示空间。
- 登录头像弹层不能被输入卡片裁切；Web 端扫码登录和 Cookie 导入能直接操作，Tauri 桌面端额外支持网页登录和同步登录。
- 已登录状态下不能通过单次点击头像直接退出，必须先展开账号操作区，再点击红色退出按钮。
- UP 主数量和公开视频数量变化时，头像选择区高度稳定，公开视频封面、标题和元信息保持对齐。
- 公开视频列表每页 5 条，超过 5 条时可以通过类似 B 站的页码分页切换；视频列表区域可以用滚轮浏览当前页。
- 已保存 UP 主进入面板后会自动尝试刷新公开视频，用户不需要先点额外刷新按钮才能看到最近视频。
- 未载入视频时，视频画面区域有明确状态，不出现大块无意图空白。
- 触控目标保持不小于 44px。
- 必须通过 `pnpm run check`。
