# 声音预设精简与自定义配置设计

## 背景

当前“声音”页的一键混音预设数量偏多，用户在真正入睡前需要扫过较长列表。用户希望内置预设大约只保留 4 个，同时新增一个独立配置入口，允许把自己调好的声音组合保存为全局混音，后续直接复用。

## 目标

- 普通白噪音内置预设从多组长列表精简为 4 个。
- 保留 ASMR 模式自己的 4 个预设，不把本次“普通声音预设过多”的问题扩展到 ASMR。
- 在声音页增加独立的“我的混音”区域，不挂在白噪音、ASMR 或其他声音的内置预设下面。
- 用户可以把当前播放或待恢复的声音组合保存为全局混音。
- 全局混音可以同时包含白噪音、ASMR、其他声音和自定义音频。
- 全局混音持久化保存，重启后仍可读取。
- 全局混音可以一键应用。
- 全局混音可以删除。
- 顶部统一播放按钮只负责播放或停止全局混音，不再按当前声音模式播放 ASMR 默认预设或其他声音分类快混。

## 第一版范围

包含：

- 精简 `PRESET_GROUPS`，普通声音只保留 4 个内置组合。
- 新增全局混音存储，路径为 `sound-presets/custom-presets.json`。
- 全局混音保存声音 ID、音量和保存时间。
- 保存时按当前混音器快照生成配置内容，快照来源不受当前声音分类限制。
- 全局混音最多保留 12 个。
- 删除全局混音只删除用户保存的混音，不影响音频文件或内置预设。

不包含：

- 编辑已有全局混音的名称和声音明细。
- 拖拽排序全局混音。
- 导入、导出配置。
- 跨设备同步。
- 删除或修改 ASMR 预设。
- 删除声音库里的声音资源。

## 架构边界

```text
SoundMixerView
  -> 生成当前声音配置快照
  -> useCustomSoundPresets 保存 / 读取 / 删除全局混音
  -> MixPlanPanel 展示推荐混音和我的混音
  -> useSoundMixer.applyPreset 应用全局混音
  -> PlayerPort
```

全局混音是“声音页用户数据”，不写入静态 `soundPresets.ts`，也不归属于某个声音模式。`soundPresets.ts` 只保留内置推荐混音定义。白噪音、ASMR、其他声音和自定义音频只影响声音库来源筛选，不影响全局混音的保存、恢复或顶部播放语义。

## 数据模型

```ts
interface CustomSoundPreset {
  id: `custom_preset:${string}`;
  name: string;
  description: string;
  items: SoundPresetItem[];
  createdAt: number;
  updatedAt: number;
}
```

全局混音 ID 使用随机 token，避免用户保存相同组合时互相覆盖。后续如果需要“最近使用去重”，可以单独设计。代码中的 `CustomSoundPreset` 和 `custom-presets.json` 继续作为既有技术标识符使用，用户界面统一展示为“全局混音”或“我的混音”。

## Component Map

`SoundMixerView`：

- 继续编排声音页。
- 生成当前可保存的声音配置快照。
- 调用全局混音 hook。
- 把全局混音和操作传给独立混音区域。

`MixPlanPanel`：

- 在同一区域展示推荐混音和我的混音。
- 提供保存当前混音按钮。
- 提供应用推荐混音、应用全局混音和删除我的混音按钮。
- 不按白噪音、ASMR 或其他声音拆分。

`ActiveMixPanel`：

- 展示当前混音内的全部声音。
- 每个声音可暂停、恢复和调音量。
- 当前无声音时展示空态。

`useCustomSoundPresets`：

- 封装读取、保存、删除和状态消息。
- 不操作播放器。
- 文案层面使用“全局混音”，不暴露“按模式配置”的理解。

`customSoundPresetStore`：

- 负责持久化、校验、归一化、数量限制。
- 继续使用既有存储路径和类型名称，不做数据迁移。

## 方案取舍

### 方案一：把全局混音混入内置预设常量

实现简单，但会把运行时用户数据和静态内置配置混在一起，也不利于持久化。

不采用。

### 方案二：全局混音独立存储，UI 合并展示

内置预设和全局混音职责清晰，应用全局混音时仍走同一个 `applyPreset` 播放入口。

不采用。用户已经明确全局混音应独立于白噪音、ASMR 和其他声音，而不是挂在某个预设列表里。

### 方案三：全局混音独立存储，独立区域展示

优点是产品概念清楚：内置预设负责快速推荐，“我的混音”负责跨全部声音保存用户自己的组合。应用时仍复用 `applyPreset` 和 `PlayerPort`。

采用。

## 失败路径

- 持久化文件不存在：返回空全局混音列表。
- 持久化文件损坏：忽略损坏内容，返回空列表。
- 当前没有可保存声音：禁用保存按钮。
- 全局混音引用的声音不存在：应用时由混音器过滤不可用声音。
- 所有声音都不可用：混音器显示已有的播放失败提示。

## 兼容性

本阶段不做破坏性数据迁移：

- 不修改 `PlayerPort`。
- 不修改声音资源路径。
- 不删除用户已有自定义音频。
- 不迁移已有全局混音存储文件。
- 内置预设数量减少属于用户可见列表精简，不影响用户已经保存的睡眠最近配置。

## 验收标准

- 普通白噪音预设显示为 4 个内置组合。
- “声音”页可以保存当前混音为全局混音。
- 保存后的全局混音显示在“推荐与我的混音”区域。
- “当前混音”和“推荐与我的混音”区域在白噪音、ASMR、XMSLEEP 分类和自定义音频标签下都可见。
- 全局混音可以包含白噪音、ASMR 和其他声音。
- 点击全局混音会播放对应声音和音量。
- 删除全局混音后列表更新。
- 没有可保存声音时不能保存全局混音。
- 顶部统一播放按钮在白噪音、ASMR、XMSLEEP 分类和自定义标签下都只恢复最近的全局混音，不按当前标签改播默认推荐或当前分类。
- ASMR 推荐混音仍保留 4 个，并统一展示在“推荐与我的混音”区域。
- 必须通过：

```bash
rtk pnpm run check
```
