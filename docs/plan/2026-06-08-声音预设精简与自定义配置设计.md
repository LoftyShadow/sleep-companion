# 声音预设精简与自定义配置设计

## 背景

当前“声音”页的一键混音预设数量偏多，用户在真正入睡前需要扫过较长列表。用户希望内置预设大约只保留 4 个，同时新增一个独立配置入口，允许把自己调好的声音组合保存成配置，后续直接复用。

## 目标

- 普通白噪音内置预设从多组长列表精简为 4 个。
- 保留 ASMR 模式自己的 4 个预设，不把本次“普通声音预设过多”的问题扩展到 ASMR。
- 在声音页增加独立的“我的配置”区域，不挂在白噪音、ASMR 或其他声音的内置预设下面。
- 用户可以把当前播放或待恢复的声音组合保存为自定义配置。
- 自定义配置可以同时包含白噪音、ASMR、其他声音和自定义音频。
- 自定义配置持久化保存，重启后仍可读取。
- 自定义配置可以一键应用。
- 自定义配置可以删除。

## 第一版范围

包含：

- 精简 `PRESET_GROUPS`，普通声音只保留 4 个内置组合。
- 新增自定义配置存储，路径为 `sound-presets/custom-presets.json`。
- 自定义配置保存声音 ID、音量和保存时间。
- 保存时按当前混音器快照生成配置内容，快照来源不受当前声音分类限制。
- 自定义配置最多保留 12 个。
- 删除自定义配置只删除用户保存的配置，不影响音频文件或内置预设。

不包含：

- 编辑已有自定义配置的名称和声音明细。
- 拖拽排序自定义配置。
- 导入、导出配置。
- 跨设备同步。
- 删除或修改 ASMR 预设。
- 删除声音库里的声音资源。

## 架构边界

```text
SoundMixerView
  -> 生成当前声音配置快照
  -> useCustomSoundPresets 保存 / 读取 / 删除用户配置
  -> CustomPresetPanel 展示独立的用户配置
  -> useSoundMixer.applyPreset 应用配置
  -> PlayerPort
```

自定义配置是“声音页用户数据”，不写入静态 `soundPresets.ts`，也不归属于某个声音模式。`soundPresets.ts` 只保留内置预设定义。

## 数据模型

```ts
interface CustomSoundPreset {
  id: `custom_preset:${string}`;
  name: string;
  description: string;
  items: SoundPresetItem[];
  createdAt: number;
  updatedAt: number;
}
```

自定义配置 ID 使用随机 token，避免用户保存相同组合时互相覆盖。后续如果需要“最近使用去重”，可以单独设计。

## Component Map

`SoundMixerView`：

- 继续编排声音页。
- 生成当前可保存的声音配置快照。
- 调用自定义配置 hook。
- 把自定义配置和操作传给独立配置区域。

`PresetGroups`：

- 展示内置预设。

`CustomPresetPanel`：

- 展示独立的“我的配置”区域。
- 提供保存当前配置按钮。
- 展示自定义配置列表。
- 提供删除自定义配置按钮。

`useCustomSoundPresets`：

- 封装读取、保存、删除和状态消息。
- 不操作播放器。

`customSoundPresetStore`：

- 负责持久化、校验、归一化、数量限制。

## 方案取舍

### 方案一：把自定义配置混入内置预设常量

实现简单，但会把运行时用户数据和静态内置配置混在一起，也不利于持久化。

不采用。

### 方案二：自定义配置独立存储，UI 合并展示

内置预设和用户配置职责清晰，应用配置时仍走同一个 `applyPreset` 播放入口。

不采用。用户已经明确自定义配置应独立于白噪音、ASMR 和其他声音，而不是挂在某个预设列表里。

### 方案三：自定义配置独立存储，独立区域展示

优点是产品概念清楚：内置预设负责快速推荐，“我的配置”负责跨声音类型保存用户自己的组合。应用时仍复用 `applyPreset` 和 `PlayerPort`。

采用。

## 失败路径

- 持久化文件不存在：返回空自定义配置。
- 持久化文件损坏：忽略损坏内容，返回空列表。
- 当前没有可保存声音：禁用保存按钮。
- 自定义配置引用的声音不存在：应用时由混音器过滤不可用声音。
- 所有声音都不可用：混音器显示已有的播放失败提示。

## 兼容性

本阶段不做破坏性数据迁移：

- 不修改 `PlayerPort`。
- 不修改声音资源路径。
- 不删除用户已有自定义音频。
- 内置预设数量减少属于用户可见列表精简，不影响用户已经保存的睡眠最近配置。

## 验收标准

- 普通白噪音预设显示为 4 个内置组合。
- “声音”页可以保存当前配置为自定义配置。
- 保存后的自定义配置显示在独立的“我的配置”区域。
- “我的配置”区域在白噪音、ASMR、其他声音模式下都可见。
- 自定义配置可以包含白噪音、ASMR 和其他声音。
- 点击自定义配置会播放对应声音和音量。
- 删除自定义配置后列表更新。
- 没有可保存声音时不能保存自定义配置。
- ASMR 预设仍保留 4 个。
- 必须通过：

```bash
rtk pnpm run check
```
