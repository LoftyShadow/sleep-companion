# B站UP主列表与最新视频刷新总览

## 目标

在“听视频”模式内实现本地保存 B 站 UP 主列表、刷新公开视频列表、点击最新视频后使用现有官方播放器播放。

## 步骤列表

1. 编写设计文档与执行计划。
2. 新增后端公开视频列表命令。
3. 新增前端 UP 主解析、保存、刷新状态和 UI 面板。
4. 接入现有听视频播放器。
5. 补充 TypeScript 与 Rust 测试。
6. 运行 `pnpm run check`。

## 依赖关系

- 前端视频播放必须继续复用 `createBilibiliPlaybackSource`。
- 本地保存必须复用 `FileSystemPort`，不新增独立数据库。
- 后端公开视频列表命令必须只接受 `mid`，不接受任意 URL。
- UI 样式必须沿用 `VideoListeningView.css` 的现有体系。

## 统一验收标准

- UP 主列表可本地保存、加载、去重和删除。
- 公开视频列表刷新成功时能展示标题、封面、时间和播放量。
- 公开视频刷新按投稿页分页获取，默认每页 5 条；投稿接口提供总数时展示总页数并支持页码翻页，投稿接口失败时直接展示错误，不再请求动态接口兜底。
- 点击公开视频后能载入现有官方 iframe 播放器。
- 刷新失败不会破坏手动链接播放。
- 所有新增文档正文为中文。
- 必须通过 `pnpm run check`。

## 风险

- B 站 WBI 投稿分页接口可能因为风控、签名规则或接口结构变化失败。
- 不同地区网络下接口响应可能不一致。
- 官方播放器仍可能因为视频本身权限、会员、地区、登录或版权策略无法播放。
- 当前第一版不做自动刷新、账号授权和用户 cookie 保存，无法导入用户自己的关注列表。
