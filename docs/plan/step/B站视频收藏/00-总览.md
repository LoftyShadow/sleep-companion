# B 站视频收藏步骤总览

## 目标

为“听视频”新增本地视频收藏，允许用户保存常听视频信息，并在后续直接从收藏列表重新载入指定视频播放。

## 步骤

1. 编写收藏设计和执行文档。
2. 新增收藏数据类型、存储函数和单元测试。
3. 新增收藏 hook 和收藏面板组件。
4. 接入 `VideoListeningView`，支持收藏当前视频、播放收藏视频和删除收藏。
5. 补充页面交互测试并运行完整验证。

## 统一验收标准

- 收藏只保存视频 ID 和展示元信息，不保存直连媒体 URL 或登录凭证。
- 当前已载入视频可加入收藏。
- 收藏列表可持久化读取。
- 点击收藏项可重新载入直连媒体播放。
- 删除收藏后列表立即更新。
- 重复收藏同一 `bvid` 时更新元信息，不出现重复卡片。
- `pnpm run check` 通过。

## 风险

- 收藏视频后，B 站视频可能被删除、转私密或触发风控，后续直连解析仍可能失败。
- IndexedDB 不可用时收藏功能不可用，但不应影响现有播放流程。
- 当前不做云同步，换浏览器、换设备或清理站点数据会丢失收藏。
