# 步骤 01：本地收藏与播放入口

## 目标

实现 B 站视频收藏的本地存储、收藏面板和播放接入。

## 涉及文件

- `src/features/videoListening/bilibiliFavoriteVideo.ts`
- `src/features/videoListening/bilibiliFavoriteVideoStore.ts`
- `src/features/videoListening/useBilibiliFavoriteVideos.ts`
- `src/features/videoListening/BilibiliFavoriteVideoPanel.tsx`
- `src/features/videoListening/VideoListeningView.tsx`
- `src/features/videoListening/VideoListeningView.css`
- `src/features/videoListening/bilibiliFavoriteVideoStore.test.ts`
- `src/features/appMode/AppWorkspace.test.tsx`

## 实现范围

- 定义收藏视频元信息类型。
- 用 `FileSystemPort` 持久化收藏列表。
- 收藏面板展示当前视频收藏状态和收藏列表。
- 已载入视频可保存到收藏。
- 点击收藏项重新走现有直连播放流程。
- 删除收藏项。

## 不做内容

- 不接入 B 站官方收藏夹。
- 不保存播放进度。
- 不保存直连音频、直连视频或备用媒体地址。
- 不增加收藏分组、搜索和批量操作。
- 不提交代码。

## 验收清单

- 收藏 store 覆盖保存、更新、删除、排序和损坏 JSON 兜底。
- 页面测试覆盖收藏当前视频、点击收藏播放和删除收藏。
- UI 文案保持中文。
- 收藏数据不包含媒体 URL 和登录凭证。
- `pnpm run check` 通过。
