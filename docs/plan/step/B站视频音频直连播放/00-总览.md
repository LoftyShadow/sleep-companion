# B 站视频音频直连播放步骤总览

## 目标

把“听视频”的普通 `BV/av` 播放从 B 站官方 iframe 改为应用自有 `<audio>` 直连播放，支持播放、暂停、音量控制、进度跳转，并在可获得视频轨时提供默认隐藏、可展开且可选择画质的视频画面。若 B 站返回 `view_points` 章节/看点，允许用户选择章节并跳转。

## 步骤

1. 编写设计和执行文档。
2. 实现直连音频 source 解析接口和 Web/Tauri 客户端。
3. 在直连 source 中补充可选视频轨和媒体代理。
4. 改造“听视频”页面为 `<audio>` 主控，并新增默认隐藏的视频画面。
5. 增加视频画质选择，默认优先稳定的 `1080p` 以内预览轨。
6. 增加进度条、时间显示、拖动跳转和可选章节选择。
7. 补测试并运行完整验证。

## 统一验收标准

- 普通视频不再渲染 B 站 iframe。
- 普通视频播放、暂停、音量由应用自己的 `<audio>` 控制。
- 普通视频进度条展示当前时间和总时长，拖动后跳转 `<audio>`。
- 响应包含章节时可以选择章节，并跳转到章节起点。
- 视频画面默认隐藏；存在视频轨时可以展开和再次隐藏。
- 存在多个视频轨时可以选择画质，默认不使用 4K 作为预览画质。
- 视频画面不可用时不影响音频直连播放。
- `ep/live` 不走 iframe，给出当前直连模式暂不支持的明确提示。
- 登录凭证不进入前端状态、DOM 或测试输出。
- `pnpm run check` 通过。

## 风险

- B 站播放地址接口可能失败或被风控。
- Tauri 桌面直连播放可能受 B 站防盗链影响，必要时后续增加 Rust 流代理。
- 视频画面是直连视频轨预览，不提供完整 DASH 音视频合成和自适应清晰度。
- 章节依赖 B 站 `view_points` 返回，不是所有视频都有章节。
- 生产 Web 需要等价后端代理，不能只依赖 Vite 中间件。
