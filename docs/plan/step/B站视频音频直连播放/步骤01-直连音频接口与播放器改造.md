# 步骤 01：直连音频接口与播放器改造

## 目标

完成普通 `BV/av` 视频的直连音频 source 获取、前端 `<audio>` 播放控制、进度跳转、可选章节选择、可选直连视频画面、画质选择和原 iframe 入口移除。

## 涉及文件

- `src-tauri/src/bilibili_direct_audio.rs`
- `src-tauri/src/lib.rs`
- `vite.config.ts`
- `src/features/videoListening/bilibiliDirectAudio.ts`
- `src/features/videoListening/BilibiliVideoPlaybackPanel.tsx`
- `src/features/videoListening/useBilibiliDirectAudioPlayer.ts`
- `src/features/videoListening/VideoListeningView.tsx`
- `src/features/videoListening/VideoListeningView.css`
- 相关测试文件

## 实现范围

- 新增直连音频 source 类型和运行时 loader。
- Tauri 命令返回直连音频 source 和可选视频轨 source。
- Vite Web API 返回可播放的代理音频 URL 和可选代理视频 URL。
- 直连响应返回视频轨列表；默认视频轨优先选择 `1080p` 以内的浏览器兼容轨道。
- 直连响应返回视频时长；若 `x/player/wbi/v2` 返回 `view_points`，同步返回章节列表。
- 页面移除普通视频 iframe，改为隐藏的原生 audio 元素。
- 页面新增进度条、当前时间、总时长和拖动跳转。
- 页面在存在章节时提供章节选择，选择后跳转到章节起点。
- 页面新增默认隐藏、可展开/隐藏的原生 video 画面。
- 页面在存在多个视频轨时提供画质选择。
- 音量滑块对普通视频启用。

## 不做内容

- 不支持 `ep` 番剧直连。
- 不支持直播直连。
- 不实现倍速、完整 DASH 自适应码率和完整音视频合成。
- 不实现进度持久化。
- 不提交代码。

## 验收清单

- 普通 `BV/av` 载入后无 iframe。
- `播放` / `暂停` 控制 `<audio>`。
- 音量滑块启用并同步。
- 进度条展示当前时间和总时长，拖动后更新 `<audio>.currentTime`。
- 章节列表只在响应包含章节时展示，选择章节后跳转到对应起点。
- 视频画面默认隐藏。
- 存在视频轨时可展开和隐藏视频画面。
- 存在多个视频轨时可选择画质，默认画质不是 4K。
- `ep/live` 有明确提示。
- 测试覆盖直连 loader 和页面交互。
- `pnpm run check` 通过。
