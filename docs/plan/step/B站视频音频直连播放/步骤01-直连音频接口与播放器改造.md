# 步骤 01：直连音频接口与播放器改造

## 目标

完成普通 `BV/av` 视频的直连音频 source 获取、前端 `<audio>` 播放控制和原 iframe 入口移除。

## 涉及文件

- `src-tauri/src/bilibili_direct_audio.rs`
- `src-tauri/src/lib.rs`
- `vite.config.ts`
- `src/features/videoListening/bilibiliDirectAudio.ts`
- `src/features/videoListening/useBilibiliDirectAudioPlayer.ts`
- `src/features/videoListening/VideoListeningView.tsx`
- `src/features/videoListening/VideoListeningView.css`
- 相关测试文件

## 实现范围

- 新增直连音频 source 类型和运行时 loader。
- Tauri 命令返回直连音频 source。
- Vite Web API 返回可播放的代理音频 URL。
- 页面移除普通视频 iframe，改为隐藏或原生 audio 元素。
- 音量滑块对普通视频启用。

## 不做内容

- 不支持 `ep` 番剧直连。
- 不支持直播直连。
- 不实现进度条和倍速。
- 不提交代码。

## 验收清单

- 普通 `BV/av` 载入后无 iframe。
- `播放` / `暂停` 控制 `<audio>`。
- 音量滑块启用并同步。
- `ep/live` 有明确提示。
- 测试覆盖直连 loader 和页面交互。
- `pnpm run check` 通过。
