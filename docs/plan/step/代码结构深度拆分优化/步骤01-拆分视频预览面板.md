# 步骤01：拆分视频预览面板

## 目标

降低 `BilibiliVideoPlaybackPanel.tsx` 复杂度，把视频预览状态机、纯计算逻辑和展示片段拆到独立文件。

## 涉及文件

- `src/features/videoListening/BilibiliVideoPlaybackPanel.tsx`
- `src/features/videoListening/useBilibiliVideoPreview.ts`
- `src/features/videoListening/bilibiliVideoPlaybackUtils.ts`
- `src/features/videoListening/VideoProgressControls.tsx`
- `src/features/videoListening/VideoSourceDetails.tsx`
- `src/features/videoListening/BilibiliVideoPlaybackPanel.test.tsx`

其中测试文件作为验证依据，本步骤没有修改测试用例。

## 输入输出

- 输入：`audioSource`、`audioRef`、播放时间、加载状态和 `onSeek`。
- 输出：用户可见的视频预览、进度、章节和媒体源详情保持不变。

## 验收标准

- 现有 `BilibiliVideoPlaybackPanel` 测试全部通过。
- 视频源错误时仍先尝试 backup，再尝试下一画质，最后切回音频。
- 进度拖动和章节选择仍调用 `onSeek`。

## 检查清单

- [x] 没有在组件内部定义子组件。
- [x] 状态副作用集中在 `useBilibiliVideoPreview`。
- [x] 纯计算逻辑不依赖 React。
- [x] CSS className 不变。
- [x] 运行目标测试，最终已通过 `rtk pnpm run check`。
