# 步骤02：拆分听视频页面

## 目标

把 `VideoListeningView.tsx` 中的业务状态和动作拆入 controller hook，让页面组件只负责布局和组件组合。

## 涉及文件

- `src/features/videoListening/VideoListeningView.tsx`
- `src/features/videoListening/useVideoListeningController.ts`
- `src/features/videoListening/VideoLinkPanel.tsx`
- `src/features/videoListening/VideoNowPanel.tsx`
- `src/features/appMode/AppWorkspace.test.tsx`
- `src/features/appMode/AppWorkspace.integration.test.tsx`

其中 `AppWorkspace` 测试文件作为播放控制回归验证依据，本步骤没有修改测试用例。

## 输入输出

- 输入：B 站登录 client、UP 主视频 loader、直连音频 loader、文件系统、全局停止请求和播放控制请求。
- 输出：听视频页面交互、收藏入口、UP 主入口和悬浮播放控制行为保持不变。

## 验收标准

- `VideoListeningView` 不直接维护主加载流程。
- 全局停止请求只消费一次。
- 悬浮播放控制请求只消费一次。
- 相关 AppWorkspace 测试通过。
