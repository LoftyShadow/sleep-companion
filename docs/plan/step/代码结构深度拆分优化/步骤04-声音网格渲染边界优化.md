# 步骤04：声音网格渲染边界优化

## 目标

把声音卡片拆为可 memo 的叶子组件，降低单个声音播放状态或音量变化时的渲染扩散。

## 涉及文件

- `src/features/mixer/SoundGrid.tsx`
- `src/features/mixer/SoundMixerView.tsx`
- `src/features/player/useSoundMixer.test.tsx`
- `src/features/appMode/AppWorkspace.integration.test.tsx`

其中测试文件作为声音播放和悬浮控制回归验证依据，本步骤没有修改测试用例。

## 输入输出

- 输入：声音列表、播放状态、音量状态和声音操作回调。
- 输出：声音卡片 UI 和交互保持不变。

## 验收标准

- `SoundCard` 接收单卡片所需 props。
- `SoundMixerView` 传给 `SoundGrid` 的主要动作 callback 保持稳定。
- 声音播放、音量调整、自定义声音删除行为保持不变。
