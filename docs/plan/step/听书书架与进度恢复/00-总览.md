# 听书书架与进度恢复总览

## 目标

为听书入口新增多本书书架、本地持久化和片段级继续播放能力。第一版使用 IndexedDB 实现 `FileSystem` 抽象，不引入原生文件系统、SQLite 或云同步。

## 步骤

1. 存储抽象
   - 新增 `FileSystemPort`。
   - 新增 IndexedDB 文件系统实现。
   - 补基础读写测试。

2. 书库服务
   - 扩展听书类型，新增书库摘要、封面和进度类型。
   - 新增 `audiobookLibraryStore`。
   - 导入文件后保存书籍 JSON、封面和书库摘要。
   - 支持打开、删除、重命名、更新进度。

3. EPUB 元数据和封面
   - 扩展 OPF 解析，读取作者和封面资源。
   - EPUB 没有封面时使用生成封面。
   - 保持既有 EPUB 分段行为不变。

4. 播放器进度恢复
   - `useAudiobookPlayer` 支持 `initialSegmentIndex`、`resetKey` 和 `onProgressChange`。
   - 切书时恢复进度，播放过程中保存进度。

5. UI 书架
   - 新增 `AudiobookLibraryPanel`。
   - `AudiobookView` 改为编排书架、朗读面板、设置和阅读器。
   - 支持导入、打开、删除和当前书重命名。

6. 验证
   - 补充单元测试和组件测试。
   - 运行 `pnpm run check`。

## 统一验收

- 多本书可以同时存在于书架。
- 每本书有独立进度。
- 关闭或刷新后仍能恢复书架和进度。
- 删除书籍不影响其他书。
- 没有封面的书有稳定生成封面。
- 完成后运行 `pnpm run check`。

## 风险

- IndexedDB 配额不足时导入失败，需要显示错误。
- EPUB 封面格式不统一，第一版只覆盖 manifest 标准路径。
- 片段级进度依赖分段结果稳定，后续改分段算法时需要兼容旧进度。
