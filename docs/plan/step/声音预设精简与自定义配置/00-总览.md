# 声音预设精简与自定义配置总览

## 目标

把普通声音内置预设精简到 4 个，并允许用户把当前声音组合保存成自己的全局混音。全局混音作为用户数据单独持久化，不和内置预设常量混在一起，也不归属于白噪音、ASMR 或 XMSLEEP 分类中的某一个标签。白噪音、ASMR、XMSLEEP 分类和自定义只影响声音库展示，不影响用户保存或恢复的混音范围。

## 执行步骤

1. 精简内置预设：减少普通白噪音预设数量，保留 ASMR 预设。
2. 全局混音存储：新增读取、保存、删除和校验逻辑。
3. 全局混音 hook：封装 UI 所需的 loading、消息和操作。
4. 独立混音 UI 改造：增加全局“推荐与我的混音”区域、保存当前混音、全局混音列表和删除按钮。
5. 测试和验证：补充 store、hook、声音页交互和预设定义测试，运行全量检查。
6. 全局播放语义修正：顶部统一播放按钮在所有声音模式下只恢复最近全局混音，播放中则停止全部。

## 统一验收标准

- 普通声音内置预设总数为 4。
- ASMR 内置预设仍为 4。
- 用户可以保存当前声音组合为全局混音。
- 全局混音能跨白噪音、ASMR 和其他声音保存声音组合。
- 全局混音能持久化读取。
- 全局混音能一键应用。
- 全局混音能删除。
- 当前没有可保存声音时，保存按钮禁用。
- “推荐与我的混音”是独立区域，不挂在任一声音标签下面。
- 顶部统一播放按钮不随声音模式改变播放目标。
- 配置 UI 不引入复杂编辑器或排序管理。
- 最终运行 `rtk pnpm run check`。

## 全局风险

- 全局混音如果引用自定义音频，删除对应音频后配置可能只剩部分声音；本阶段交给混音器过滤不可用声音。
- 普通内置预设数量减少是用户可见变化，需要测试固定数量，避免后续再次膨胀。
- 推荐混音区域和“我的混音”要保持职责清晰，避免再次把用户混音混入来源筛选。
- 顶部统一播放按钮不能再依赖 ASMR 默认预设或 XMSLEEP 分类，否则用户会误以为全局混音是按标签局部保存的。

## 破坏性更新说明

无接口级破坏性更新。用户可见变化是普通声音内置预设列表被精简；不删除任何声音资源或用户数据。
