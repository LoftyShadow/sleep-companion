# 声音预设精简与自定义配置总览

## 目标

把普通声音内置预设精简到 4 个，并允许用户把当前声音组合保存成自己的配置。自定义配置作为用户数据单独持久化，不和内置预设常量混在一起，也不归属于白噪音、ASMR 或其他声音中的某一个模式。

## 执行步骤

1. 精简内置预设：减少普通白噪音预设数量，保留 ASMR 预设。
2. 自定义配置存储：新增读取、保存、删除和校验逻辑。
3. 自定义配置 hook：封装 UI 所需的 loading、消息和操作。
4. 独立配置 UI 改造：增加“我的配置”区域、保存当前配置、自定义配置列表和删除按钮。
5. 测试和验证：补充 store、hook、声音页交互和预设定义测试，运行全量检查。

## 统一验收标准

- 普通声音内置预设总数为 4。
- ASMR 内置预设仍为 4。
- 用户可以保存当前声音组合为自定义配置。
- 自定义配置能跨白噪音、ASMR 和其他声音保存声音组合。
- 自定义配置能持久化读取。
- 自定义配置能一键应用。
- 自定义配置能删除。
- 当前没有可保存声音时，保存按钮禁用。
- “我的配置”是独立区域，不挂在任一内置预设分组下面。
- 配置 UI 不引入复杂编辑器或排序管理。
- 最终运行 `rtk pnpm run check`。

## 全局风险

- 自定义配置如果引用自定义音频，删除对应音频后配置可能只剩部分声音；本阶段交给混音器过滤不可用声音。
- 普通内置预设数量减少是用户可见变化，需要测试固定数量，避免后续再次膨胀。
- 内置预设区域和“我的配置”区域要保持职责清晰，避免再次把用户配置混入模式预设。

## 破坏性更新说明

无接口级破坏性更新。用户可见变化是普通声音内置预设列表被精简；不删除任何声音资源或用户数据。
