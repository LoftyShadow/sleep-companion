# 步骤02：声音库查找与默认展示密度

## 目标

降低声音页默认信息密度，新增搜索和完整库展开能力，让用户更快找到声音。

## 涉及文件

- `src/features/mixer/SoundGrid.tsx`
- `src/features/mixer/SoundMixerView.css`
- `src/features/mixer/SoundMixerView.mobile.css`
- `src/features/mixer/SoundGrid.css`
- 相关测试文件

## 待办拆分

- [ ] 在声音页新增搜索输入和清空按钮。
- [ ] 默认只展示当前筛选下的精选数量。
- [ ] 增加“显示全部”和“收起完整库”切换。
- [ ] 搜索时展示全部匹配结果，不再套默认数量限制。
- [ ] 无匹配结果时展示清晰空状态。
- [ ] 给声音音量 range 补稳定 `id/name`，如果与步骤 04 冲突则在步骤 04 统一完成。
- [ ] 更新测试覆盖默认收起、搜索、显示全部。

## 实现要点

- 在声音库标题区加入搜索输入。
- 默认只展示当前筛选下的前一批声音。
- 搜索时展示匹配结果；搜索为空时可点击“显示全部”。
- 搜索匹配名称、可访问名称和标签。
- 保留自定义音频导入入口和现有分类筛选。
- 不引入虚拟列表库，第一版用轻量展开控制。

## 验收标准

- 默认展示数量少于完整声音数。
- 搜索“雨”能缩小声音列表。
- 点击“显示全部”后可看到完整列表。
- 现有播放、音量和删除自定义音频能力不回退。
