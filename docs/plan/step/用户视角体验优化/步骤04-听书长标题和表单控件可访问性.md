# 步骤04：听书长标题和表单控件可访问性

## 目标

缩短听书长标题对视觉和辅助技术的干扰，并补齐表单控件稳定标识。

- `src/features/videoListening/VideoNowPanel.tsx`
- `src/features/videoListening/VideoProgressControls.tsx`
- 相关测试文件

## 待办拆分

- [ ] 增加听书短标题 helper。
- [ ] 当前朗读 H1 使用短标题展示，完整标题写入 `title`。
- [ ] 书架打开按钮和删除按钮的 `aria-label` 使用短标题。
- [ ] 给自定义音频导入、听书导入、视频音量、视频进度、声音音量等控件补稳定 `id/name`。
- [ ] 测试覆盖长标题短标签和至少一个表单控件标识。
- [ ] Chrome MCP 复查 DevTools issue 是否消失或减少到历史范围。

## 实现要点

- 新增听书标题截断 helper。
- 长标题视觉展示短标题，完整标题放入 `title`。
- 打开和删除按钮的 `aria-label` 使用短标题。
- range、file、select 等控件补稳定 `id` 和 `name`。
- 不改变书籍标题本身，不迁移书架存储。

## 验收标准

- 长标题不会撑开听书控制区。
- 读屏按钮名称不再包含完整超长书名。
- Chrome DevTools 不再提示本次覆盖控件缺少 `id` 或 `name`。
- 现有导入和播放测试不回退。

## 提交边界

提交听书、声音页表单标识、听视频表单标识和相关测试。不要提交 UP 主刷新逻辑或睡眠页布局改动。

如果表单标识补充范围过大导致测试抖动，优先保留听书长标题改动，把表单标识拆成更小补丁。
