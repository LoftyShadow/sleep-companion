# 步骤01-睡眠入口与应用模式接入

## 目标

在应用顶层新增“睡眠”模式，保持现有“声音 / 听书 / 听视频”行为不变。

## 涉及文件

- `src/features/appMode/appModeTypes.ts`
- `src/features/appMode/AppModeSwitcher.css`
- `src/features/appMode/AppWorkspace.tsx`
- `src/features/appMode/AppWorkspace.css`
- `src/features/appMode/AppWorkspace.mobile.css`
- `src/features/sleepSession/SleepSessionView.tsx`
- `src/features/sleepSession/SleepSessionView.css`

## 实现要点

- `AppMode` 增加 `sleep`。
- 模式切换按钮增加“睡眠”。
- 工作台标题增加“睡眠入口”。
- 新增睡眠页面占位和基础布局。
- 移动端底部导航从 3 列改为 4 列。

## 验收标准

- “睡眠”入口可见。
- 点击“睡眠”后显示睡眠页面。
- 切回其他模式后原页面状态不丢失。
- 移动端导航按钮不换行、不遮挡。
