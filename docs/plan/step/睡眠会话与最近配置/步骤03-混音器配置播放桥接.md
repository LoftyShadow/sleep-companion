# 步骤03-混音器配置播放桥接

## 目标

让睡眠入口可以复用声音混音器当前配置，并请求混音器按最近配置播放。

## 涉及文件

- `src/features/player/useSoundMixer.ts`
- `src/features/player/useSoundMixer.test.tsx`
- `src/features/mixer/SoundMixerView.tsx`
- `src/features/sleepSession/sleepSessionTypes.ts`

## 实现要点

- `useSoundMixer` 增加按配置播放的动作。
- `SoundMixerView` 上报当前可复用配置快照。
- `SoundMixerView` 消费一次性配置播放请求。
- 配置播放前停止旧声音，再按配置播放新声音。
- 不修改 `PlayerPort` 签名。

## 验收标准

- 快照包含声音 ID、名称和音量。
- 播放请求只消费一次。
- 恢复配置时按配置音量播放。
- 不存在的声音 ID 会被忽略。
- 播放失败时沿用现有混音器错误处理。
