# 步骤05-淡出能力边界预留

## 目标

记录淡出播放的后续实现边界，避免当前睡眠入口把尚未完成的淡出能力暴露给用户。

## 当前阶段处理

本阶段不实现实际淡出曲线，也不在 UI 中显示“淡出”开关。原因是淡出需要播放器支持临时音量缩放，不能直接覆盖用户配置音量，否则会污染最近配置和混音器音量状态。

## 后续推荐实现

- 在 `useSoundMixer` 增加临时播放音量倍率。
- 倒计时进入最后 N 秒时，由顶层发出淡出倍率。
- 淡出倍率只影响播放实例，不修改 `volumes`。
- 取消定时器或重新开始播放时恢复原始播放音量。
- 第一版优先覆盖声音混音器；听书和听视频另行评估。

## 验收标准

- 当前阶段没有对用户承诺淡出。
- 文档说明淡出为何拆为后续步骤。
- 后续实现时不得污染用户保存的配置音量。

## 检查清单

- [x] 睡眠入口 UI 没有淡出开关。
- [x] 最近配置数据结构没有保存未实现的淡出字段。
- [x] 后续实现边界已记录。
