# ASMR 控制台 MVP 设计

## 目标

在现有白噪音调音台基础上，增加一个可真实播放的 ASMR 控制台 MVP。第一版先接入 10 个来自本地 XMSLEEP 项目的真实音频素材，让用户能快速感受“近距离触发音 + 多轨混音”的基本效果。

## 第一版范围

第一版包含：

- 从 `/home/niemingzhi/IdeaProjects/XMSLEEP` 复制 10 个真实 ASMR 候选音频到本项目。
- Web、Linux、Windows 使用 `public/audio/asmr/` 下的 `ogg` 文件播放。
- Android 使用 `src-tauri/gen/android/app/src/main/res/raw/` 下同名 `ogg` 文件播放。
- 继续复用现有 `PlayerPort` 抽象，UI 不直接依赖平台播放器。
- 当前界面增加“白噪音 / ASMR 控制台”模式切换。
- ASMR 控制台展示 10 个 ASMR 声音卡片，每个声音可播放、暂停、调音量。
- ASMR 控制台提供少量一键组合，便于快速试听。
- 统一播放/停止按钮在 ASMR 模式下默认播放 ASMR 推荐组合，播放中则停止全部。
- 自定义音频入口继续保留，方便用户后续导入自己的 ASMR 音频。
- ASMR 卡片视觉素材使用真实音频生成的波形图，不使用空占位图。

第一版不包含：

- 从网络下载新素材。
- 做素材商店或在线素材库。
- 声音搜索、收藏、标签筛选。
- 自定义 ASMR 预设。
- 左右声道、空间位置、随机触发、节奏编排。
- 音频裁剪、降噪、响度标准化或转码流水线。
- Android 后台播放和锁屏控制。

## 界面设计

界面沿用当前左右双栏结构：

- 左侧顶部增加模式切换按钮，用户可在“白噪音”和“ASMR 控制台”之间切换。
- 左侧总览卡根据当前模式显示标题、说明和当前播放摘要。
- 左侧预设区域在白噪音模式显示原有一键混音，在 ASMR 模式显示 ASMR 触发组合。
- 右侧声音库根据当前模式切换：
  - 白噪音模式显示原 17 个内置白噪音和自定义音频。
  - ASMR 模式显示 10 个 ASMR 内置音频和自定义音频。
- 自定义音频入口保留在右侧顶部，两种模式都可见。

ASMR 卡片和白噪音卡片复用同一套播放控件，避免新增播放分支。卡片图片使用由音频文件生成的波形图，用户能看到真实音频的形态，而不是泛化占位图。

## 播放架构

ASMR 声音作为新的内置声音接入：

```text
React UI
  -> useSoundMixer
  -> PlayerPort
      -> WebAudioPlayer：Web、Linux、Windows
      -> AndroidHybridPlayer
          -> AndroidNativePlayer：内置白噪音和内置 ASMR
          -> WebAudioPlayer：自定义音频
```

ASMR 声音和白噪音声音共用 `SoundDefinition`：

```ts
interface SoundDefinition {
  id: SoundId;
  name: string;
  sourceKind: "built-in" | "custom";
  androidResourceName?: string;
  imageSrc: string;
  sources: AudioSourceDefinition[];
}
```

新增的 ASMR ID 进入 `BuiltInSoundId`，这样 Android 原生播放器可以继续通过 `androidResourceName` 定位 raw 资源。

## 预设策略

第一版只提供内置 ASMR 推荐组合，不做用户自定义：

- 近耳清理：掏耳素材为主，低音量叠加纸张摩擦。
- 桌面敲击：键盘、打字机和纸张形成轻节奏。
- 液体微声：沸水、气泡和车顶雨点形成连续细响。
- 颗粒行走：碎石脚步和落叶脚步形成颗粒摩擦感。

预设仍通过 `useSoundMixer.applyPreset` 执行，避免复制播放逻辑。

## 验收标准

- 仓库内存在 10 个 ASMR Web 音频文件和 10 个 Android raw 音频文件。
- 仓库内存在 10 张由 ASMR 音频生成的波形图。
- `SoundDefinition` 中的 ASMR 音频路径和 Android raw 资源名都能被测试验证。
- UI 能看到“ASMR 控制台”模式切换。
- 切换到 ASMR 模式后，能看到 10 个 ASMR 声音和 ASMR 触发组合。
- 点击 ASMR 预设会通过 `PlayerPort` 播放对应声音。
- 统一播放按钮在 ASMR 模式下能播放默认 ASMR 组合，播放中能停止全部。
- 必须通过：

```bash
pnpm run check
git diff --check
```

Android 真机播放仍需用户手动验证。agent 除非实际运行过 Android 真机，不得声称 Android 真机验证通过。
