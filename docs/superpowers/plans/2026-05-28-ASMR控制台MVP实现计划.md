# ASMR 控制台 MVP 实现计划

## 目标

用 XMSLEEP 本地项目中的真实音频素材，完成一个简单可用的 ASMR 控制台 MVP。第一版重点验证素材选择、模式切换、预设播放和多轨调音效果。

## 执行步骤

- [x] 确认 XMSLEEP 中存在可用 ASMR 候选音频。
- [x] 记录第一版 10 个素材、来源文件和边界。
- [x] 复制 10 个真实 ASMR 音频到 `public/audio/asmr/`。
- [x] 复制 10 个真实 ASMR 音频到 Android `res/raw/`。

## 关键约束

- 不用占位音频。
- 不从网络临时抓取未知授权音频。
- UI 只能依赖 `PlayerPort` 抽象，不能直接调用平台播放器。
- ASMR 内置音频必须同步 Web 和 Android 两套资源，避免 Android 缺 raw 文件。
- 不改变现有白噪音 17 个声音的可见行为。
- 不删除或回滚已有自定义音频能力。
- 文档正文必须使用中文。

## 剩余风险

- XMSLEEP 的汇总文档说明音频来自多个来源，但本 MVP 尚未逐条登记作者和许可证；正式公开发布前需要补齐素材授权台账。
- ASMR 音频响度没有统一处理，第一版只设置预设音量，实际听感需要手动调试。
- Android 真机播放需要用户后续运行验证。
