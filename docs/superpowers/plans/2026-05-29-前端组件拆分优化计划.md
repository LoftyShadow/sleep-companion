# 前端组件拆分优化计划

## 目标

控制前端入口文件膨胀，把应用级路由、模式切换和声音调音台拆到清晰的能力模块中，不改变现有用户可见行为。

## 执行步骤

- [x] 新增 `features/appMode`，移动 `AppMode` 和 `AppModeSwitcher`。
- [x] 新增 `features/mixer`，移动声音模式配置和 `SoundMixerView`。
- [x] 精简 `App.tsx`，只保留应用路由和运行时依赖接线。
- [x] 更新听书视图对模式切换组件的导入。
- [x] 拆分调音台局部 UI，并保持 `SoundMixerView` 只做状态编排。
- [x] 根据 React skill 复核结果拆分听书局部 UI。
- [x] 优化调音台摘要派生，避免 render 中多次遍历声音集合。
- [x] 按功能拆分 `App.css`，保留全局共享样式和现有 className。
- [x] 运行聚焦测试和完整门禁。
