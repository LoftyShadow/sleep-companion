# 前端组件拆分优化计划

## 目标

控制前端入口文件膨胀，把应用级路由、模式切换和声音调音台拆到清晰的能力模块中，不改变现有用户可见行为。

## 执行步骤

- [x] 新增 `features/appMode`，移动 `AppMode` 和 `AppModeSwitcher`。
- [x] 新增 `features/mixer`，移动声音模式配置和 `SoundMixerView`。
- [x] 精简 `App.tsx`，只保留根组件转发。
- [x] 新增 `AppWorkspace`，承接应用工作区编排、运行时依赖接线和模式可见性切换。
- [x] 更新听书视图对模式切换组件的导入。
- [x] 拆分调音台局部 UI，并保持 `SoundMixerView` 只做状态编排。
- [x] 根据 React skill 复核结果拆分听书局部 UI。
- [x] 优化调音台摘要派生，避免 render 中多次遍历声音集合。
- [x] 删除 `App.css`，把全局基础样式、共享 UI 样式和工作区壳子样式分别迁移到明确边界。
- [x] 运行聚焦测试和完整门禁。

## 风险和约束

- CSS 拆分只移动规则归属，不改 className，不引入 CSS Modules。
- `App.tsx` 和 `App.css` 不再作为后续业务编排或业务样式承载点；新增能力应落到对应 feature 或共享样式边界。
- 不调整 `PlayerPort`、`TtsEnginePort`、声音目录和预设数据结构。
- `package.json` 当前存在用户已有版本号改动，本次不触碰。
