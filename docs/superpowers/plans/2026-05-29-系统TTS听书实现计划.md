# 系统 TTS 听书实现计划

## 目标

新增第一版听书功能：用户导入或粘贴文本书稿，选择系统音色后连续朗读。实现时保留 `TtsEnginePort`，后续可以接云端 TTS、音频缓存或 Android 原生 TTS。

本轮追加 EPUB 导入支持：用户可导入非加密 `.epub`，系统按 EPUB spine 顺序逐章读取 XHTML 正文并生成朗读片段。EPUB 导入不能把整本书展开进文本编辑框，也不引入完整阅读器能力。

本轮继续优化 EPUB 听书展示：分段列表按章节切换，界面上方显示当前播放章节，并支持选择章节、上一章和下一章。章节切换从目标章节第一段开始朗读，底层仍复用既有片段连续播放逻辑。

本轮追加拖拽导入：Web、Linux 桌面和 Windows 桌面等支持拖放的平台，可以把 `.txt`、`.md`、`.markdown` 或 `.epub` 书稿直接拖入导入区域。拖入后复用现有 `handleBookFiles` 导入入口，不新增独立解析路径。

本轮调整章节片段展示：EPUB 章节拆分后，章节名称只保留在章节导航和章节选择器中，当前章节内的每个朗读片段不再重复显示章节名称。

本轮继续调整朗读片段展示：分段列表限制高度并允许滚动，朗读推进时自动保证当前片段可见，用户停止滚动 2 秒后自动定位回当前片段，并提供手动定位到当前正在阅读的按钮。

## 关键约束

- UI 只依赖 `TtsEnginePort`，不能直接调用 `speechSynthesis`。
- Linux Tauri 桌面端不直接依赖 WebKitGTK 的 `speechSynthesis`，而是通过 Tauri 原生 command 调用 `spd-say`。
- Linux 原生 TTS 暂不伪装暂停能力；`supportsPause = false` 时 UI 使用停止语义。
- EPUB 支持只覆盖非加密、可通过 OPF spine 定位到 XHTML/HTML 文档的电子书。
- EPUB 导入使用 `@zip.js/zip.js` 按条目读取，不把整本 EPUB 当纯文本读取，也不把全部正文回填到 textarea。
- EPUB 片段列表按章节渲染，不能一次性铺开所有章节片段；章节选择、上一章和下一章都从章节第一段开始朗读。
- 章节名称不在当前章节内每个朗读片段上重复显示，避免长列表产生重复视觉噪声。
- 片段列表限制高度并支持用户滚动；播放推进时当前朗读片段自动滚入可见范围，但章节开头不强制居中。
- 用户停止滚动 2 秒后，片段列表自动定位回当前朗读片段。
- 片段列表下方提供“定位到当前正在阅读”按钮，用户手动滚开后可以回到当前朗读片段。
- 片段正文不使用省略号隐藏；过长文本通过分段器拆短，默认单片段硬上限约 180 字。
- 拖拽导入只能复用已有单文件导入入口；第一版不做批量书稿导入。
- EPUB 内脚本不执行，只用 `DOMParser` 抽取文本，并忽略 `script`、`style`、`nav` 等不适合朗读的节点。
- 分段优先使用平台内置 `Intl.Segmenter`，不额外引入分词依赖。
- 不接云 TTS，不新增 API key、网络请求或后端代理。
- 不做音频缓存，避免提前引入文件存储复杂度。
- 不改变现有 `PlayerPort` 和白噪音/ASMR 播放行为。
- 顶层模式切换只改变界面可见性，不能隐式停止 `PlayerPort` 或 `TtsEnginePort`。
- 声音调音台常驻挂载；听书在用户首次进入后挂载并保持挂载，切换模式不能卸载已打开的功能区。
- 如果未来需要全局停止全部声音，应新增显式全局控制，不复用模式切换。
- 文档正文保持中文。

## 参考项目结论

已参考 `/home/niemingzhi/RustroverProjects/readest` 的 TTS 设计。当前实现只吸收句级分段和 TTS 客户端抽象两个轻量点，不复制 Foliate/SSML mark/Edge TTS/Android 前台服务等完整阅读器能力。

本轮 EPUB 支持继续参考 `readest` 的 Foliate 装载方式：EPUB 先作为 ZIP 容器读取，再通过 `META-INF/container.xml`、OPF `manifest` 和 `spine` 定位章节。当前项目不复制 Foliate 阅读器、CFI、渲染器、目录树或资源解密架构，只保留听书分段所需的最小解析。

## 剩余风险

- 不同浏览器和 WebView 的系统 TTS 音色、暂停和继续行为不完全一致。
- Linux 原生 TTS 依赖用户系统安装并配置 `speech-dispatcher`、`spd-say` 和底层合成器。当前机器已验证 `spd-say` 可以出声，但不同发行版可能需要额外安装语音包。
- Android WebView 可能不暴露 `speechSynthesis`，需要后续 Kotlin 原生 TTS 适配器。
- EPUB 只做轻量文本抽取；复杂排版、图片书、脚本化 EPUB、加密 EPUB 或 DRM 内容不支持。
- PDF 仍不支持，用户需要先提供纯文本或 EPUB 书稿。
- 两套功能同时播放时，最终混音由系统音频栈负责；当前实现保证应用层不主动互相停止或改写彼此音量。
