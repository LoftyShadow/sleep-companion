# B站听视频实现计划

## 目标

新增“听视频”模式，第一版只支持 B 站官方外链播放器嵌入。用户粘贴 B 站链接后，应用解析 `BV`、`av` 或 `ep` 标识并载入官方播放器。

本轮补充体验细节：点击“载入视频”后通过 `autoplay=1` 尝试自动播放，并在链接输入区提供“粘贴”按钮读取系统剪贴板文本。

## 关键约束

- 只使用 B 站官方 `player.bilibili.com/player.html` 外链播放器。
- 不抓取真实音视频流，不下载、不缓存、不转码。
- 不隐藏官方播放器后只播放音频。
- 不绕过 B 站登录、会员、地区、版权、广告或其它限制。
- 自动播放只通过官方播放器参数尝试，不做浏览器策略绕过。
- 链接解析只做本地字符串处理，不请求 B 站非公开接口。
- 听视频模式切换只改变可见性，不主动停止 `PlayerPort` 或 `TtsEnginePort`。
- 文档正文保持中文。

## 验收命令

先运行聚焦测试：

```bash
rtk pnpm vitest run src/features/videoListening src/features/appMode
```

最后运行完整门禁：

```bash
rtk pnpm run check
rtk git diff --check
```

## 剩余风险

- B 站官方播放器对部分视频可能要求登录、会员、地区或版权条件，应用不做绕过。
- 桌面 WebView 对第三方 iframe 的策略可能与浏览器不同，需要按实际平台验证。
- `b23.tv` 短链接如果不包含可解析路径，第一版不会联网跟随跳转，因此无法识别。
