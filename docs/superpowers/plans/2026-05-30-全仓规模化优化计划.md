# 全仓规模化优化计划

## 范围

本计划覆盖全仓代码优化盘点和第一批低风险落地。当前阶段不做行为变更、不引入新依赖、不做目录级大迁移。

## Component Map

- Page / Route：`AppWorkspace` 只保留应用模式切换、懒加载业务视图和顶层布局。
- Feature Component：`SoundMixerView`、`AudiobookView`、`VideoListeningView` 继续承载各自业务视图。
- Hook：`useRuntimePlayer` 管理播放器生命周期，`useGlobalSleepTimer` 管理全局定时停止状态。
- Utils：后续候选包括 `useSoundMixer` 纯函数、听书语言识别和 EPUB 文本解析工具。
- Style File：本阶段不拆样式；后续优先拆 `SoundMixerView.css`。

## 执行步骤

1. 写入全仓优化设计文档，记录规模信号、采纳方案和暂不采纳方案。
2. 新增 `useRuntimePlayer`，从 `AppWorkspace` 移出播放器创建和销毁副作用。
3. 新增 `useGlobalSleepTimer`，从 `AppWorkspace` 移出倒计时、取消、完成和全局停止请求编号逻辑。
4. 更新 `AppWorkspace`，让它只组合模式切换、定时控件和三个业务视图。
5. 运行项目质量门禁。

## 第二批执行步骤

1. 新增 `soundMixerState`，承载混音状态规则，并补充纯函数单测。
2. 更新 `useSoundMixer`，复用 `soundMixerState`，让 hook 只保留播放器命令和 React 状态同步。
3. 新增 `speechLanguage`，承载听书语言识别和音色选择规则，并补充纯函数单测。
4. 更新 `useAudiobookPlayer`，复用 `speechLanguage`，避免语言规则继续散落在 hook 内。
5. 运行 `pnpm run check` 完整验证。

## 第三批执行步骤

1. 新增 `epubXml`，集中 XML/HTML 解析、元素查询和 ZIP 内路径解析。
2. 新增 `epubPackage`，集中 `container.xml` 和 OPF package 读取规则。
3. 新增 `epubTextExtraction`，集中章节标题和正文提取规则。
4. 新增 `epubSegments`，集中 spine 到 `AudiobookSegment` 的转换。
5. 简化 `epubImport`，让它只保留文件入口、ZIP 读取和顶层组装。
6. 为正文提取补充聚焦测试，并保留现有 EPUB 端到端导入测试。
7. 运行 `pnpm run check` 完整验证。

## 风险控制

- 当前工作区已有未提交改动，本次只新增优化文档和小范围 hook 拆分，不回滚已有改动。
- `useGlobalSleepTimer` 必须保留原有 1 秒倒计时行为和完成时递增 `globalStopRequestId` 的协议。
- `useRuntimePlayer` 必须保留卸载时销毁播放器的行为。
- 不修改 audiobook 的当前实现文件，避免干扰已有 TTS 听书改动。

## 验证

- 必跑：`pnpm run check`。
- 重点观察：`AppWorkspace` 相关测试、全局定时停止测试、播放器 hook 相关测试。
- 如果 Android SDK、`adb` 或移动端工具链缺失，不声明 Android 真机验证通过。

## 后续优化队列

- 拆分 `SoundMixerView.css`，按现有组件边界移动样式。
- 评估是否将 `useSoundMixer.ts` 的开发日志抽成专用日志适配器；仅当多个播放器 hook 继续复用日志格式时再做。
