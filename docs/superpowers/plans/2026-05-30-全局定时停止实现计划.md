# 全局定时停止实现计划

## 目标

新增顶层定时停止控制条，让用户在任意模式启动倒计时。时间到后统一停止声音、听书和听视频。

## 关键约束

- 定时器是顶层通用功能，不属于某一个模式。
- 定时时长支持预设选择和自定义分钟输入。
- 倒计时结束要让各功能域自己同步 UI 状态，不能只停底层播放器。
- 不主动挂载用户从未打开过的听书或听视频视图。
- 听视频停止通过清空 iframe 源实现，不抓取或控制 B 站内部播放器。
- 文档正文保持中文。
