# 桌面窗口栏美化实现计划

## 步骤

1. 新增桌面窗口栏设计文档和实现计划。
2. 新增 `AppTitleBar` 组件和同名样式文件。
3. 在 `App.tsx` 中挂载窗口栏，并保留 `AppWorkspace` 的业务职责。
4. 调整 `tauri.conf.json`，关闭桌面窗口原生装饰。
5. 调整 `src-tauri/capabilities/default.json`，允许窗口控制命令。
6. 补充窗口栏渲染和按钮行为测试。
7. 将桌面端滚动条改为滚动时短暂出现的右侧浮层指示条。
8. 运行 `pnpm run check` 验证。

## 验收

- Web 测试环境不显示桌面窗口栏。
- Tauri 桌面环境显示窗口栏。
- 点击最小化、最大化和关闭按钮会调用对应窗口命令。
- 非桌面平台不显示窗口按钮。
- 窗口栏不显示平台名称。
- 滚动条不常驻、不挤压页面布局，并贴近窗口右侧显示。
- 本地质量门禁通过。
