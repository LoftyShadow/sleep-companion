# Web 桌面 UI/UX 重设计实现计划

## 目标

在不改变播放逻辑的前提下，重设计 Web、Linux 和 Windows 共用主界面的展示结构，重点改善声音页的首屏信息架构和操作路径。

## 执行步骤

- [x] 调整全局设计 token、背景和共享玻璃面板质感。
- [x] 把 `AppWorkspace` 顶部改为工作台级导航和全局控制区。
- [x] 把声音页改成“场景总览 / 主播放 / 快速预设 / 声音细调”的展示流程。
- [x] 把听书页改成“书稿概览 / 主朗读 / 导入设置 / 内容跟读”的展示流程。
- [x] 把听视频页改成“链接载入 / 当前收听 / 官方播放源”的展示流程。
- [ ] 运行质量门禁。
- [ ] 启动本地预览并做桌面首屏视觉检查。

## 风险和约束

- 本次只改样式和文档，不改业务状态流。
- 视觉检查依赖本机浏览器或截图工具；如果无法自动截图，需要说明验证缺口。
- Android 窄屏会继承部分 CSS，但不作为本次专项验收目标。
