# 悬浮播放控制实现计划

## 目标

新增一个跨模块悬浮播放控制入口，让用户在任意模式快速控制全局播放/暂停、展开模块播放列表，并在悬浮区内设置定时停止。

## 关键约束

- 悬浮控制属于工作台级能力，不属于任意单个模块。
- 顶层不直接依赖 `PlayerPort` 或 `TtsEnginePort` 的具体播放行为，只转发模块级命令。
- 三个模块继续由各自内部状态同步 UI 和错误提示。
- 全局播放/暂停通过模块请求号批量触发，不绕过模块内部状态。
- 定时停止只迁移展示位置，不改变 `useGlobalSleepTimer` 的倒计时和停止逻辑。
- 不主动重构现有播放器、TTS 或 B 站 iframe 逻辑。
- 不删除当前全局定时停止能力。
- 文档正文保持中文。
