# 前端我的登录入口实现计划

## 范围

本轮只实现前端“我的”tab 和邮箱密码登录入口，不实现后端认证业务。

## 步骤

1. 新增前端登录入口设计文档，明确 API 契约、状态边界和本轮非目标。
2. 扩展 `AppMode`，把“我的”加入现有模式切换器。
3. 新增 `src/features/account/authApi.ts`，封装登录请求、后端 base URL 和 envelope 错误。
4. 新增 `src/features/account/AccountView.tsx` 和 `AccountView.css`。
5. 在 `AppWorkspace` 中挂载 `AccountView`，并保持其他播放模块状态独立。
6. 新增账号页和 API 适配层测试。
7. 运行目标测试和仓库主门禁。

## 验收标准

- 应用模式切换器中出现“我的”tab。
- 点击“我的”后展示登录表单。
- 登录表单可以把邮箱和密码提交给可注入的登录函数。
- 登录成功后展示当前账号邮箱和显示名。
- 登录失败后展示错误信息。
- 后端地址默认使用 `http://127.0.0.1:3817`，并可通过 `VITE_BACKEND_BASE_URL` 覆盖。
- `rtk pnpm run check` 通过。

## 破坏性更新说明

本轮无破坏性更新。新增 tab 不改变声音、听书和听视频的播放状态管理；登录态暂时不持久化，也不影响现有本地音频数据。
