# 全局定时停止设计

## 目标

新增一个跨模式通用的定时停止功能。用户可以在任意模式设置倒计时；倒计时结束后，应用统一停止声音调音台、听书朗读和听视频播放。

## 范围

第一版包含：

- 在顶层模式切换下方显示定时停止控制条，三个模式都可见。
- 支持选择常用倒计时时长。
- 支持开始和取消定时。
- 定时运行时显示剩余倒计时。
- 倒计时结束后停止全部可播放域：
  - 声音调音台停止所有环境声和自定义声音。
  - 听书停止当前 TTS 朗读。
  - 听视频卸载当前 B 站 iframe 播放器。
- 定时结束后显示已停止状态。

第一版不包含：

- 后台系统级定时任务。
- 跨应用重启恢复定时器。
- 自定义到秒的复杂编辑。
- 分模式单独定时。
- 操作系统睡眠、关机或锁屏控制。

## 架构

定时器放在 `AppWorkspace` 顶层，维护剩余秒数和定时状态。倒计时归零时，顶层递增一个 `stopRequestId`，将停止信号传给三个功能域。

```text
SleepTimerControl
  -> AppWorkspace stopRequestId + 1
  -> SoundMixerView stopAll
  -> AudiobookView stop
  -> VideoListeningView clear iframe source
```

不直接在顶层调用功能域内部 hook，避免破坏各视图自己的状态封装。各功能域收到新的停止信号后自行同步 UI 状态。

## UI 设计

定时器是一个紧凑控制条，显示：

- 标题“定时停止”。
- 当前状态：未开启、剩余时间或已停止。
- 常用时长预设列表。列表使用和听书章节选择器一致的自绘下拉样式。
- 自定义分钟输入框，允许用户输入自己的倒计时时长。
- 开始按钮。
- 取消按钮。

控制条保持在三个模式上方可见，不进入某个具体功能卡片内部。

## 错误处理

- 如果声音播放器尚未初始化，定时结束仍会发出停止信号；声音视图挂载后不会补发旧信号。
- 如果某个功能域尚未打开，定时结束不强制挂载该功能域。
- B 站 iframe 没有可控停止 API，第一版通过清空当前视频源停止播放。

## 验收标准

- 定时器启动后显示倒计时。
- 定时器支持常用预设和用户自定义分钟数。
- 定时器可以取消。
- 倒计时结束后调用声音调音台停止逻辑。
- 倒计时结束后调用听书停止逻辑。
- 倒计时结束后清空听视频播放器。
- 定时器在“声音 / 听书 / 听视频”三个模式都可见。
- 必须通过：

```bash
rtk pnpm run check
```
