# 悬浮播放控制设计

## 目标

新增一个全局悬浮播放控制入口，让用户在任意模式中直接控制整体播放、查看三个声音模块的播放状态，并设置定时停止：

- 声音调音台。
- 听书朗读。
- 听视频收听。

第一版聚焦播放和暂停，不替代各模块内部的完整设置、导入、音量和章节控制。

## 范围

第一版包含：

- 在工作台右下角显示一个三键悬浮遥控器。
- 第一键是全局播放/暂停，负责批量播放或暂停当前可控模块。
- 第二键是模块列表，点击后展开三个模块的紧凑控制面板。
- 第三键是定时停止，点击后展开定时设置面板。
- 遥控器提供收回按钮，点击后缩成右下角紧凑入口，避免长时间遮挡主内容。
- 每个模块展示当前状态、摘要和主操作。
- 声音调音台支持从悬浮面板播放当前混音或暂停当前混音。
- 听书支持从悬浮面板播放、暂停、继续或停止当前朗读。
- 听视频在已载入来源后支持从悬浮面板播放或暂停；未载入来源时引导用户进入听视频模块。
- 点击悬浮区之外的任意位置会收起已展开面板。
- 悬浮面板不切断模式之间已有的独立播放能力。

第一版不包含：

- 悬浮面板内编辑音量、章节、书稿或视频链接。
- 系统级媒体通知、锁屏控制或后台服务。
- 对普通 B 站视频 iframe 内部音量做额外控制。
- 跨应用重启恢复悬浮面板展开状态。

## 架构

悬浮控制放在 `AppWorkspace` 顶层。顶层不直接调用各播放器底层实现，而是通过轻量命令和状态快照与三个功能域通信。

```text
FloatingPlaybackControl
  -> AppWorkspace playbackControlRequestIds
  -> SoundMixerView / AudiobookView / VideoListeningView
  -> 各模块内部已有播放逻辑

SoundMixerView / AudiobookView / VideoListeningView
  -> AppWorkspace playbackControlState
  -> FloatingPlaybackControl 显示状态

SleepTimerControl
  -> FloatingPlaybackControl timer panel
  -> AppWorkspace useGlobalSleepTimer
```

这个方案延续已有 `globalStopRequestId` 的跨模块信号模式，但命令只通过模块级请求号转发，不扩展底层 `PlayerPort` 或 `TtsEnginePort`。

## 状态模型

每个模块向顶层上报：

- `status`：`idle`、`playing`、`paused`、`loading` 或 `unavailable`。
- `summary`：当前播放内容或待机说明。
- `actionLabel`：悬浮按钮上的主操作文字。
- `canToggle`：当前是否能执行主操作。

顶层保留默认状态，避免模块尚未打开时悬浮面板出现空白。

## 全局播放策略

- 如果已有模块正在播放，全局按钮只向播放中的模块发送暂停请求。
- 如果没有模块正在播放，全局按钮向可切换且已就绪的模块发送播放请求。
- 未载入来源的听视频模块不会被全局播放强制启动；用户仍需先在听视频模块载入来源。

## UI 设计

悬浮遥控器固定在视口右下角，并避开移动端安全区域。视觉方向是“睡前遥控器”：主播放键更宽，列表和定时是两个紧凑工具键，整体保持轻玻璃质感但不遮挡主工作区。用户可以把遥控器收回成紧凑状态，紧凑状态只展示全局播放/暂停图标按钮；旁边的竖向三点按钮只负责恢复完整遥控器，不执行播放动作。

模块面板展开后位于遥控器上方，包含三个模块行：

- 左侧显示模块名和状态摘要。
- 右侧提供一个主操作按钮。
- 播放中状态使用现有绿色/青色体系中的强调态；暂停或停止使用更克制的浅色按钮。
- 定时面板复用已有 `SleepTimerControl`，但容器适配悬浮宽度。
- 面板最大宽度受控，移动端宽度不超过可视区域。

为了避免遮挡主内容，桌面端和移动端都保留底部安全间距；面板只承载控制，不放解释性说明。

## 错误处理

- 声音播放器尚未初始化时，声音模块行显示准备中且不可操作。
- 听书环境不支持 TTS 或没有可朗读文本时，由听书模块原有错误提示处理。
- 听视频没有载入来源时，悬浮按钮会切换到听视频模块让用户载入链接，不尝试构造来源。
- 模块执行播放或暂停失败时，沿用模块内部已有错误提示。

## 验收标准

- 悬浮按钮在三个模式中都可见。
- 悬浮区常驻显示全局播放、模块列表和定时三个按钮。
- 悬浮面板显示声音、听书、听视频三个模块。
- 点击声音模块主操作可以播放默认混音，再次点击可以暂停混音。
- 点击听书模块主操作可以播放默认文本，播放中再次点击可以暂停或停止。
- 听视频载入来源后，悬浮面板可以暂停和恢复视频收听。
- 未载入听视频来源时，悬浮面板不会报错式失败，而是进入听视频模块。
- 点击定时按钮后可以设置定时停止，顶部工作台不再重复显示定时条。
- 点击悬浮区外部后，模块列表或定时面板会自动收起。
- 点击收回按钮后，悬浮遥控器缩成紧凑状态，仍可通过图标按钮执行全局播放/暂停；点击竖向三点按钮后恢复模块列表和定时按钮。
- 必须通过：

```bash
rtk pnpm run check
```
